# Ücretsiz Kaynak Repoları

Takipçilerle paylaşılan ücretsiz kaynak repo listesi. İçerik videosu: 60 saniyede 3 repo.

Reeldeki söz: *"Yoruma REPO yaz, sana özelden 3 tane daha değerli repo göndereceğim."*

İşte listenin tamamı — videodaki 3 + bonus 3 repo. Yorum yazan takipçiye bu sayfanın linki gönderilir.

---

## 📹 Videodaki 3 Repo

### 1. public-apis — Bedava API Listesi
⭐ **~498.000 yıldız** · [github.com/public-apis/public-apis](https://github.com/public-apis/public-apis)

Kategorilere ayrılmış, ücretsiz kullanılabilen yüzlerce API: hava durumu, film, oyun,
kripto, müzik, NASA... Hepsi tek listede, sürekli güncellenir.

**Ne işe yarar?** Projen için backend uydurmana gerek yok — gerçek veriyle çalış.

### 2. free-programming-books — Ücretsiz Kitap Arşivi
⭐ **~401.000 yıldız** · [github.com/EbookFoundation/free-programming-books](https://github.com/EbookFoundation/free-programming-books)

Tüm dillerde ücretsiz programlama kitapları, kurslar, cheat sheet'ler.
**Türkçe bölümü de var.**

**Ne işe yarar?** Üniversite değil, bu arşiv yeter — sıfırdan senior seviyeye kaynak.

### 3. project-based-learning — Proje Rehberi
⭐ **~289.000 yıldız** · [github.com/practical-tutorials/project-based-learning](https://github.com/practical-tutorials/project-based-learning)

Dil dil ayrılmış, adım adım **gerçek proje** tutorial'ları: kendi editörünü yaz,
işletim sistemi kur, oyun motoru yap.

**Ne işe yarar?** Tutorial cehennemi bitir — portfolyoya dönüşecek gerçek projeler.

## 🎁 Bonus: Yorum Yazana Vaat Edilen 3 Repo

### 4. awesome-selfhosted
⭐ ~250.000 yıldız · [github.com/awesome-selfhosted/awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted)

Abonelik ödemeyi bırak: kendi sunucunda çalıştırabileceğin yüzlerce ücretsiz alternatif
(Google Drive → Nextcloud, Notion → Outline, Trello → Kanboard...).

### 5. developer-roadmap
⭐ ~320.000 yıldız · [github.com/kamranahmedse/developer-roadmap](https://github.com/kamranahmedse/developer-roadmap)

Hangi yoldan ilerleyeceğini şemayla gösteren yol haritaları: Frontend, Backend,
DevOps, AI Engineer... Her teknoloji "önce bunu öğren" sırasıyla.

### 6. the-algorithms
⭐ ~210.000 yıldız · [github.com/TheAlgorithms/Python](https://github.com/TheAlgorithms/Python)

Tüm klasik algoritmalar, Python'da (ayrıca Java, C++, JS, Go versiyonları var).
Mülakat hazırlığının tek kaynağı.
